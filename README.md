# Smart-Daily-Activity-Recommendation-System
Smart Daily Activity Recommendation System is a machine learning-based application that suggests suitable daily activities based on a user’s current condition. The system takes inputs such as mood, energy level, time of day, day type, and previous activity, and predicts the most appropriate activity like study, exercise, relaxation, socializing, or sleep.

The model is trained using a synthetic dataset generated with logical rules to simulate real-life behavior patterns. A Random Forest classifier is used to learn these patterns and make accurate predictions. The system also includes a user-friendly interface built using Streamlit, allowing users to interact with the model and receive instant recommendations.

This project demonstrates the practical application of machine learning in improving daily productivity and decision-making.
